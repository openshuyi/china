# 中华文明考古地图页面设计方案

## 1. 设计目标

创建一个现代化、交互性强的考古地图页面，帮助用户通过地理空间维度探索中华文明的遗址分布，理解不同文化圈之间的联系与差异。

## 2. 页面架构

### 2.1 整体布局

```
┌─────────────────────────────────────────────────────────┐
│  炫酷背景光晕效果                                        │
├─────────────────────────────────────────────────────────┤
│  页面标题区（玻璃态卡片）                                │
│  - 标签：空间分布视图                                    │
│  - 标题：考古遗址地图                                    │
│  - 描述：从遗址的地域分布、时间层位与核心发现...         │
├─────────────────────────────────────────────────────────┤
│  粘性筛选栏（玻璃态悬浮）                                │
│  - 地区筛选（全部、华北、黄河中游、长江下游、中原、西南）│
│  - 时期筛选（全部、旧石器时代、新石器时代、青铜时代等）  │
│  - 视图模式切换（地图视图/列表视图）                    │
├─────────────────────────────────────────────────────────┤
│  主内容区                                                │
│  ┌─────────────────┐  ┌─────────────────────────────┐  │
│  │  交互式地图      │  │  遗址列表（可折叠）           │  │
│  │  - 遗址标记点    │  │  - 遗址卡片                  │  │
│  │  - 文化圈区域    │  │  - 坐标信息                  │  │
│  │  - 点击交互      │  │  - 时期标签                  │  │
│  │  - 缩放控制      │  │  - 重要程度标识              │  │
│  └─────────────────┘  └─────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│  遗址详情模态框（点击遗址后显示）                        │
│  - 遗址名称、时期、地区                                 │
│  - 坐标信息                                             │
│  - 核心发现                                             │
│  - 历史意义                                             │
│  - 关联文物（如有）                                     │
└─────────────────────────────────────────────────────────┘
```

### 2.2 响应式设计

- **桌面端**（≥768px）：地图和列表并排显示
- **移动端**（<768px）：地图全屏，列表可折叠

## 3. 技术方案

### 3.1 地图库选择

**推荐方案：React Leaflet**

**理由：**
- 轻量级，无需 API 密钥
- 开源免费
- 与 React 生态良好集成
- 支持自定义标记和交互
- 社区活跃，文档完善

**替代方案：**
- Mapbox GL JS（功能强大但需要 API 密钥）
- Google Maps（需要 API 密钥，有费用）

### 3.2 核心依赖

```json
{
  "leaflet": "^1.9.4",
  "react-leaflet": "^4.2.1",
  "@types/leaflet": "^1.9.8"
}
```

### 3.3 动画库

继续使用 **Framer Motion**（项目已安装），保持与时间轴页面一致的动画效果。

## 4. 功能设计

### 4.1 地图视图

**核心功能：**
1. **遗址标记点**
   - 不同时期使用不同颜色
   - 重要程度影响标记大小
   - 悬停显示基本信息
   - 点击打开详情模态框

2. **文化圈区域**
   - 使用多边形或圆圈表示
   - 半透明填充，避免遮挡标记
   - 不同文化圈使用不同颜色

3. **地图控制**
   - 缩放控制
   - 全屏切换
   - 重置视图

4. **地图样式**
   - 使用浅色底图（CartoDB Positron）
   - 符合项目整体设计风格

### 4.2 列表视图

**功能：**
- 卡片式展示遗址信息
- 支持按地区和时期筛选
- 点击卡片在地图上定位
- 显示遗址重要程度标签

### 4.3 筛选功能

**筛选维度：**
1. **地区筛选**
   - 全部
   - 华北
   - 黄河中游
   - 长江下游
   - 中原
   - 西南

2. **时期筛选**
   - 全部
   - 旧石器时代
   - 新石器时代
   - 新石器时代晚期
   - 青铜时代早期
   - 青铜时代
   - 晚商

3. **视图模式切换**
   - 地图视图
   - 列表视图
   - 混合视图（地图+列表）

### 4.4 遗址详情模态框

**展示内容：**
- 遗址名称
- 时期
- 地区
- 坐标（经纬度）
- 核心发现
- 历史意义
- 关联文物（如有）
- 相关时间线事件（如有）

## 5. 视觉设计

### 5.1 设计风格

参考时间轴页面的设计风格：
- **背景光晕**：使用渐变光晕营造氛围
- **玻璃态效果**：使用 backdrop-blur 和半透明背景
- **动画过渡**：使用 Framer Motion 实现流畅动画
- **设计令牌**：使用 fumadocs-ui 的设计令牌（fd-primary, fd-border, fd-card 等）

### 5.2 颜色方案

**时期颜色编码：**
- 旧石器时代：#ef4444（红色）
- 新石器时代：#f59e0b（橙色）
- 青铜时代：#8b5cf6（紫色）
- 其他时期：#3b82f6（蓝色）

**文化圈颜色：**
- 华北：rgba(59, 130, 246, 0.15)
- 黄河中游：rgba(245, 158, 11, 0.15)
- 长江下游：rgba(16, 185, 129, 0.15)
- 中原：rgba(139, 92, 246, 0.15)
- 西南：rgba(236, 72, 153, 0.15)

### 5.3 标记点设计

- **普通遗址**：圆形标记，直径 20px
- **重要遗址**：圆形标记，直径 28px，带光晕效果
- **悬停效果**：放大 1.2 倍，增加阴影
- **选中效果**：显示脉冲动画

## 7. 用户体验优化

### 7.1 交互设计

1. **快速定位**
   - 点击列表中的遗址，地图自动定位到该遗址
   - 点击地图上的标记，列表自动滚动到对应卡片

2. **智能提示**
   - 遗址数量统计（显示在筛选栏）
   - 空状态提示（当筛选结果为空时）

3. **键盘导航**
   - 支持使用方向键在遗址间切换
   - Enter 键打开详情

### 7.2 性能优化

1. **懒加载**
   - 地图组件懒加载
   - 遗址详情按需加载

2. **虚拟滚动**
   - 列表视图使用虚拟滚动（当遗址数量较多时）

3. **缓存策略**
   - 地图瓦片缓存
   - 筛选结果缓存

## 8. 可访问性

- 键盘导航支持
- ARIA 标签
- 屏幕阅读器友好
- 高对比度模式支持
- 焦点指示器

## 10. 风险评估

### 10.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 地图库兼容性问题 | 中 | 选择成熟稳定的 React Leaflet |
| 性能问题（遗址数量多） | 中 | 实现虚拟滚动和懒加载 |
| 移动端适配 | 低 | 响应式设计和测试 |

### 10.2 设计风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 视觉风格不一致 | 低 | 参考时间轴页面设计 |
| 信息过载 | 中 | 合理的信息层级和折叠设计 |
| 交互复杂 | 低 | 提供清晰的用户引导 |

## 11. 成功指标

- 用户能够通过地图快速找到感兴趣的遗址
- 筛选功能准确有效
- 页面加载时间 < 2秒
- 移动端体验良好
- 与时间轴页面风格一致
